What PhysResponse measures

PhysResponse tests how generated motion changes when gravity, friction, or initial speed is varied under controlled conditions.

Recovering physical parameters

Scene-conditioned simulator inversion estimates the effective gravity, friction, and initial speed behind generated motion.

Scoring event outcomes

Near- and far-boundary events are scored separately. For a registered pair, both generated endpoints must match their own reference outcomes for the event to count as a success.
